# Placeholder provenance

All project artwork is an original geometric architectural study generated by
`tools/create_placeholders.py`. The two eye icons are original geometric drawings.
The quiet audio loop is an original additive sine synthesis, generated by the same script.
No downloaded art, anime frames, commercial music, voices, or external story text.
The UI uses DejaVu Sans supplied by the existing Ren'Py runtime (not copied here).

Reserved asset classes: backgrounds, characters, compositions, CG, overlays, particles.
Only backgrounds and overlays are populated at this milestone.
